## Реализация в проекте

Конвейер обработки объектов на изображении (OpenCV):

- Загрузка изображения
- Морфологическая обработка (эрозия, дилатация)
- Выделение объектов
- Вычисление признаков объектов (площадь, периметр, удлинненость)
- Поворот объектов согласно выбранному способу
- Отображение промежуточных и финальных результатов

Общие утилиты:

- `include/image.h`, `src/image.cpp` — класс-обёртка для изображения и функция `ShowImages` для компоновки нескольких изображений в одном окне

## Зависимости

- CMake 3.18+
- C++17 совместимый компилятор
- OpenCV (core, imgcodecs, imgproc, highgui)
- VTK (для 3D визуализации)
- NVIDIA CUDA Toolkit (для сборки `with_cuda`)
- Опционально: Qt5 Widgets (для выбора файла через диалог и 3D отображения; можно отключить)

Пример пакетов для Ubuntu/Debian (версии могут отличаться):

```bash
sudo apt update
sudo apt install cmake build-essential libopencv-dev
sudo apt install libvtk9-dev 
# Для Qt-файлового диалога (опционально)
sudo apt install qtbase5-dev
# CUDA Toolkit устанавливается из официальных репозиториев NVIDIA
```

Примечания по CUDA:

- Требуется видеокарта NVIDIA и установленный драйвер + CUDA Toolkit
- В CMake выставлена архитектура: `native`

## Сборка

Опции CMake:

- `-DENABLE_QT=ON|OFF` — использовать Qt6 для диалога выбора файла (по умолчанию ON)
- `-DCMAKE_CUDA_ARCHITECTURES=native|<arch>` — архитектура CUDA (по умолчанию native)
- `-DCMAKE_BUILD_TYPE=Release|Debug` — тип сборки (по умолчанию Release)

Сборка:

```bash
mkdir -p build
cd build
cmake -DENABLE_QT=ON ..
cmake --build . -j
```

В результате будет собран исполняемый файл:

- `build/with_opencv` — реализация на OpenCV (CPU)

## Запуск

Проект поддерживает два способа выбора входного изображения:

1) С Qt (ENABLE_QT=ON) — при запуске откроется диалог выбора файла. Аргументы командной строки не требуются.
2) Без Qt (ENABLE_QT=OFF) — путь к изображению обязателен аргументом.

Примеры:

```bash
# Qt включён (откроется диалог)
./with_opencv

# Qt отключён (нужно передать путь)
./with_opencv ../images/1.jpg
```

Управление:

- Отображение идёт в нескольких окнах (мозаика шагов обработки)
- Закрытие: нажмите клавишу ESC в активном окне для выхода
