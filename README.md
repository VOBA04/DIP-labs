# ЛР №1 — Обработка изображений (OpenCV + CUDA)

БГУИР, ВМСиС, 2025

Проект для лабораторной работы по курсу ЦОСиИ (часть 2). Содержит две реализации базового конвейера обработки изображений:

- Вариант А (авторский): собственные CUDA-ядра — исполняемый файл `with_cuda`
- Вариант Б (библиотечный): на OpenCV — исполняемый файл `with_opencv`

Набор тестовых изображений лежит в каталоге `images/`.

## Условие лабораторной работы (кратко)

На основе методички №1 реализовать не менее двух алгоритмов обработки изображений и сравнить два подхода:

- Вариант A — авторская реализация (без готовых «черных ящиков»)
- Вариант Б — с применением стандартной библиотеки (NumPy / OpenCV / scikit-image / PIL и др.)

Обязательные требования:

- Использовать, как минимум, два алгоритма (например, фильтрация, бинаризация, выделение контуров с оператором Собеля/Превитта, морфологические операции, преобразование каналов, переход в градации серого и пр.)
- Добиться максимального удаления лишней информации (шумы, фон, засветы)
- Результат — изображение, где чётко видны контуры объекта и его содержимое, посторонние детали удалены

## Что реализовано в данном проекте

Две параллельные реализации конвейера выделения объекта и контуров.

### OpenCV (CPU) — `src/mains/main.cpp`

- Загрузка изображения и представление в HSV
- Пороговая сегментация по каналу насыщенности S (`inRange`)
- Морфологическая обработка маски (комбинация эрозии/дилатации с разными ядрами)
- Выделение области интереса по маске и преобразование в оттенки серого
- Выделение контуров оператором Собеля (свёртка с ядрами Sobel)
- Отображение промежуточных результатов (мозаика окон)

### CUDA (GPU, авторские ядра) — `src/mains/main_cuda.cpp`, `src/cuda/cuda_processing.cu`

- Собственные CUDA-ядра: `BgrToGray`, `BgrToHsi/HsiToBgr`, `InRange`, `Erode`, `Dilate`, `BitwiseAnd`, `Sobel`, `ConvertFloatToUint8`
- Аналогичный конвейер: разбивка на BGR-каналы → HSI → порог по S → морфологическая фильтрация → маскирование → серый → Собель
- Визуализация промежуточных шагов

Общие утилиты:

- `include/image.h`, `src/image.cpp` — класс-обёртка для изображения и функция `ShowImages` для компоновки нескольких изображений в одном окне
- `include/cuda/cuda_image.cuh` — RAII-обёртка для размещения/копирования данных на GPU

## Зависимости

- CMake 3.18+
- C++17 совместимый компилятор
- OpenCV (core, imgcodecs, imgproc, highgui)
- NVIDIA CUDA Toolkit (для сборки `with_cuda`)
- Опционально: Qt6 Widgets (для выбора файла через диалог; можно отключить)

Пример пакетов для Ubuntu/Debian (опционально, версии могут отличаться):

```bash
sudo apt update
sudo apt install cmake build-essential libopencv-dev
# Для Qt-файлового диалога (опционально)
sudo apt install qt6-base-dev
# CUDA Toolkit устанавливается из официальных репозиториев NVIDIA
```

Примечания по CUDA:

- Требуется видеокарта NVIDIA и установленный драйвер + CUDA Toolkit
- В CMake выставлены архитектуры: `50 52 60 61 70 72 75 80 86 89 90`

## Сборка

Опции CMake:

- `-DENABLE_QT=ON|OFF` — использовать Qt6 для диалога выбора файла (по умолчанию ON)

Сборка:

```bash
mkdir -p build
cd build
cmake -DENABLE_QT=ON ..
cmake --build . -j
```

В результате будут собраны два исполняемых файла:

- `build/with_opencv` — CPU-реализация на OpenCV
- `build/with_cuda` — GPU-реализация с собственными CUDA-ядрами

## Запуск

Проект поддерживает два способа выбора входного изображения:

1) С Qt (ENABLE_QT=ON) — при запуске откроется диалог выбора файла. Аргументы командной строки не требуются.
2) Без Qt (ENABLE_QT=OFF) — путь к изображению обязателен аргументом.

Примеры:

```bash
# Qt включён (откроется диалог)
./with_opencv
./with_cuda

# Qt отключён (нужно передать путь)
./with_opencv ../images/1.jpg
./with_cuda   ../images/1.jpg
```

Управление:

- Отображение идёт в нескольких окнах (мозаика шагов обработки)
- Закрытие: нажмите клавишу ESC в активном окне для выхода
